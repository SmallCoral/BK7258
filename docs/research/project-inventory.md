# 初次项目检索记录

> 归档日期：2026-11-13。历史记录；AP/CP 与处理器核数的表述以后续模组能力记录为准。

这是一个**围绕博通集成（Beken）BK7258 芯片的嵌入式开发项目，目前处于开发资料和示例代码准备阶段**，面向“立创·实战派 BK7258”开发板。

我查看了目录，也读取了压缩包里的说明和部分源码：

| 位置 | 当前内容 |
|---|---|
| `Document/` | 开发资料，包括示例源码、烧录工具、参考原理图和 GPIO 寄存器表 |
| `Firmware/` | 空，尚未放入正式固件工程 |
| `Hardware/` | 空，尚未放入自己的硬件设计工程 |

[demo.zip](/D:/dev/qrs/other/BK7258/Document/立创·实战派BK7258/2、参考历程/demo.zip) 中有 **20 个示例工程**，涵盖 GPIO、ADC、UART、I²C、按键、传感器、SD 卡、Wi-Fi、蓝牙音频、摄像头、LCD 触摸屏、LVGL 界面及音乐播放。

技术上主要是 **C 语言 + FreeRTOS，使用 Beken SDK、CMake/Make 构建**，示例按 AP/CP 分开组织。

资料还提供了“小智”项目的拉取地址和 AI 玩具开发板原理图，说明它可用于探索 **AI 语音终端、智能玩具和带屏联网设备**；目前本地还没有完整的小智应用源码。

**现有文件尚不足以直接编译**：示例引用的 `bk_avdk_smp_sdk`、公共 `components`、`cmake` 和构建脚本均未包含在当前目录或压缩包中。
