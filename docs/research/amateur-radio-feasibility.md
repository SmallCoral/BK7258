# 业余无线电可行性调研（历史方向）

> 归档日期：2026-11-13。用户后续选择 AI 桌面助手，此方向仅保留研究记录。
> 以下保留当时答复；本机文件链接对应的仓库资料见 [资料索引](../SOURCES.md)。

**可以用来做业余无线电设备的主控，但单独这颗模组不能直接充当常见的短波、144 MHz 或 430 MHz 收发机。**

BK7258 自带的射频部分用于 **2.4 GHz Wi-Fi 和蓝牙**。它的“最高 480 MHz”是 CPU 主频，不是无线电收发频率，不能通过改固件就变成 U/V 段手台。[官方芯片说明](https://wiki.lckfb.com/zh-hans/bk7258md/bk7258-mod/chip-description.html)

结合它的屏幕、音频、串口和联网能力，可以考虑这些方向。以下是工程可行性判断，仍需要开发相应固件：

| 想做的设备 | BK7258 负责什么 | 还需要什么 |
|---|---|---|
| **带屏 FM 对讲机** | 频率设置、频道管理、屏幕、按键、PTT 控制 | 对应频段的射频收发模块、天线及音频外围 |
| **现有电台的遥控面板** | 显示频率与模式，通过 Wi-Fi 传递控制指令，可扩展音频传输 | 支持 CAT 等控制协议的电台、接口电路和协议适配 |
| **摩尔斯练习器、自动电键** | 点划计时、侧音、训练界面、控制电台键控 | 电键、蜂鸣器或喇叭；连接电台时需适配键控接口 |
| **APRS 数据终端** | 数据处理、显示、联网；可研究音频调制解调 | 无线电收发机、音频/PTT 接口；做移动定位时另加 GNSS |
| **窄带 SDR 接收机** | 处理外部送入的基带信号、解调、显示频谱 | 射频滤波、混频/本振、合适的 I/Q 采样硬件；开发难度较高 |

其中，“电台负责射频，外部处理器负责音频、控制和数字通信”本身就是常见架构。[ARRL 接口说明](https://www.arrl.org/files/file/OTA%20Magazine/OTA%20FT8.pdf)

例如，做一台带屏对讲机，可以采用：

**BK7258（界面、控制、联网） ↔ VHF/UHF 收发模块 ↔ 天线**

这里真正决定工作频段、发射功率、接收灵敏度的是外接收发部分。BK7258 自带的 Wi-Fi 天线不能直接拿来当这套电台的天线。

**如果你想用现有资料做第一个业余无线电项目，我更推荐“电台遥控面板”或“带屏 FM 对讲机”。** 它们能用上 BK7258 的优势；做 SDR 则还需要验证采样同步、音频通道性能和 DSP 算法，当前项目没有现成的实现。
