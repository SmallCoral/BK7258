# BK7258 模组能力调研

> 归档日期：2026-11-13。资料与官方文档调研，尚未进行硬件实测。
> 以下保留当时答复；本机文件链接对应的仓库资料见 [资料索引](../SOURCES.md)。

我结合本地原理图、20 个示例工程、立创官方文档和 Beken 的小智方案看了一遍。**这个 BK7258 模组最适合做“能联网、能听说、能显示或拍照”的小型智能设备**，例如 AI 玩具、桌面语音助手、蓝牙音箱、儿童相机和带屏控制面板。

它可以直接承担设备主控，运行你的业务程序。它的主要优势集中在：

- **无线连接**：2.4 GHz Wi-Fi 6、BLE，以及经典蓝牙音频应用。
- **音频处理**：集成音频 ADC/DAC，可接麦克风采音、经外接功放驱动喇叭。
- **图像与显示**：支持摄像头接口、JPEG 编解码、H.264 硬件编码，以及屏幕显示和图像加速。
- **外设控制**：UART、I²C、SPI、PWM、ADC 等，可以连接传感器、按键和驱动电路。以上能力见[立创芯片说明](https://wiki.lckfb.com/zh-hans/bk7258md/bk7258-mod/chip-description.html)。

立创当前文档确认的模组型号为 **BK7258QN88616，具有 640 KiB SRAM 和 16 MiB PSRAM**，有空间容纳屏幕帧缓冲、音频缓冲等数据；具体使用还受固件内存分配影响。[内存说明](https://wiki.lckfb.com/zh-hans/bk7258md/advanced-guide/ram-regions.html)

可以落地的方向如下。表中的“可扩展”是根据硬件能力作出的工程判断，不代表当前资料已经提供完整成品程序。

| 方向 | 可以实现什么 | 现有基础与需要补的部分 |
|---|---|---|
| **AI 语音助手、陪伴玩具** | 语音对话、播放回答、显示表情，加入摄像头后做拍照问答 | Beken 已有小智参考方案；需要麦克风、功放、喇叭及云端服务，屏幕和摄像头可选 |
| **蓝牙音箱、故事机、音乐播放器** | 手机连接后播放音乐，播放本地 MP3/WAV、故事和提示音 | 本地有 `bt_a2dp_sink`、`music_player`；需要功放、喇叭，本地大容量内容可放 TF 卡 |
| **带屏控制面板、桌面信息屏** | 触摸菜单、设备状态、传感器数据、天气时钟、电子工牌 | 本地有 LVGL、触摸、按键、电量显示示例；联网业务与界面需要自己整合 |
| **儿童相机、小型可视终端** | 摄像头取景、拍照、屏幕预览；进一步扩展录像或 Wi-Fi 图传 | 本地 `dvp_lcd_demo` 已提供摄像头预览路径；存储、图传和远程查看仍需开发 |
| **录音设备、语音留言机** | 采集声音、保存录音、回放或上传服务器 | 有音频采集、播放和存储基础；录音文件管理及云端转写需整合 |
| **联网传感器、设备控制器** | 读取温湿度、运动等传感器，通过网络上报，控制灯光或执行器 | 有 GPIO、ADC、I²C、UART、Wi-Fi、BLE 示例；需要相应传感器、驱动电路和业务协议 |

上述本地示例都在 [demo.zip](/D:/dev/qrs/other/BK7258/Document/立创·实战派BK7258/2、参考历程/demo.zip) 中。蓝牙音箱用途也有[官方 A2DP 教程](https://wiki.lckfb.com/zh-hans/bk7258md/advanced/bluetooth.html)支持。

**AI 方向尤其适合它，但要理解模块和云端的分工。** Beken 官方的小智方案已经提供配网、设备激活、语音交互、拍照问答、MCP 工具支持和双屏动画。通常由 BK7258 负责采音、拍照、联网、播放和控制硬件，云端完成对话及视觉理解。按它的计算与内存规模，不适合在本地运行通用大语言模型。[官方小智方案](https://gitee.com/bekencorp/smp_ai_xiaozhi)

本地资料还给出了更具体的产品组合：

- :codex-file-citation{path="D:/dev/qrs/other/BK7258/Document/立创·实战派BK7258/3、参考原理图/AIDK_AI玩具开发板_原理图.pdf" purpose="source"} 包含摄像头、麦克风、喇叭、双屏、运动传感器、外接 NFC 芯片及马达驱动。因此，可以进一步设计成**有表情、能感知摇晃、刷卡触发内容的互动玩具**。
- :codex-file-citation{path="D:/dev/qrs/other/BK7258/Document/立创·实战派BK7258/3、参考原理图/BK7258模组设计参考.pdf" purpose="source"} 提供了屏幕、触摸、TF 卡、摄像头和音频外围参考，并预留音频回采电路，可作为语音打断等功能的硬件基础。

做方案时，有几个边界会直接影响工作量：

1. **买到模组后仍要配外围。** 屏幕、摄像头、麦克风、功放、扬声器和充电管理电路，都需要按产品需求配置。芯片支持某个接口，也需要匹配的器件驱动和引脚分配。
2. **语音唤醒存在算法授权。** 官方小智方案当前默认的 Beken 离线唤醒引擎需要购买授权；参考方案也提供按键启动对话。[官方说明](https://gitee.com/bekencorp/smp_ai_xiaozhi/blob/main/README.zh.md)
3. **供电要考虑无线发射的瞬时需求。** 模组设计指南推荐 3.3 V，并要求单模组电源具备至少 500 mA 的供电能力；这是电源能力要求，不是说模块始终消耗 500 mA。[硬件指南](https://wiki.lckfb.com/zh-hans/bk7258md/bk7258-mod/hardware.html)
4. **当前项目还需要补齐开发依赖。** 本地示例引用的 SDK 和公共板级组件尚未包含在目录中；小智参考方案面向的开发板也需要按你的实际硬件适配。

另外修正一下上一轮的表述：我把 AP/CP 简称为“双核”不够准确。它们是两套固件，**AP 自身以双核 SMP 运行，模组介绍标注的是三核**。[模组介绍](https://wiki.lckfb.com/zh-hans/bk7258md/)、[AP/CP 架构说明](https://wiki.lckfb.com/zh-hans/bk7258md/advanced-guide/ap-cp-architecture.html)

**结合你现有的资料，我最推荐做“带屏 AI 桌面助手”：先实现按键对话、声音播放和屏幕表情，再加入摄像头问答或传感器交互。** 这个方向能充分使用它的音频、显示和联网能力，也有官方方案与本地例程可供借鉴。
