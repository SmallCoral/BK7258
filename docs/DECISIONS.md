# 桌灵设计决策

- 自制桌灵底板使用 BK7258 模组、USB-C 供电、CH340K 串口、模拟麦克风和差分扬声器输出。PCB 与原理图使用嘉立创 EDA 专业版文件夹化工程归档。
- 原理图取消板载复位键和对话键，保留由 USB 断电重上电进入烧录的方式。语音启动和打断由 Windows 上位机提供。
- 样机选择 Windows 11 与 USB 串口直连。固定中文指令在 Windows 本机识别，状态和执行结果显示在本机面板。
- LCD 接口保留在硬件设计中。样机测试中屏幕与背光未亮，现场展示使用 Windows 上位机。
- YQ045 与 ESP32-S3 的离线语音曾独立验证两段播放可被「退出」打断。五段试听音频与 YQ045 实验已退出桌灵交付范围。
