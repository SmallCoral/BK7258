## 当前工程建议

- 基于当前电脑环境，以 Windows 为首个目标平台。
- BK7258 作为桌面交互终端；托盘程序在当前登录用户下运行，负责状态采集及动作执行。
- USB 用于供电和烧录；Wi-Fi 局域网连接设备与电脑。
- 先用网页和电脑麦克风做原型，再采购配套屏幕、音频和主板。
- 优先实现 CPU、内存、网速、进程查询，媒体与音量控制，打开指定应用/项目及工作模式。
- 每个动作使用明确参数并返回实际结果；重复请求应避免重复执行。
- 设备按键启动和打断语音；离线唤醒、免按键对话、摄像头和电池留到后续。
- 云模型密钥留在电脑端。状态面板直接使用本地数据，AI 按请求获取必要状态。
