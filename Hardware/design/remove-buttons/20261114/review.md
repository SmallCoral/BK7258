# 无按键版原理图

2026-11-14。按用户要求取消两颗板载按钮及其专用外围，并完成模组 65 脚电源名称与去耦取值的纠正。本次只交付原理图、BOM 和说明，PCB 由用户处理。

| 变更 | 结果 |
| --- | --- |
| SW1 复位键及 C11 | 删除；CEN/模组 3 脚无外部连接，标为未连接 |
| SW2 对话键、C12、R5 | 删除；P28/模组 10 脚标为未连接 |
| RESET_N、KEY_TALK_N | 已从实际导出网表消除，相关导线、网络标签与独立电源/地符号一并清理 |
| 65 脚 | 正确名称为 **VDDGPIO**，原稿混用了 VIO 名称与另一电源的 4.7 µF 说明 |
| C10 | 按模组官方参考 C15 采用 **1 µF 对地去耦**；实际器件绑定改为 CL10A105KB8NNNC / C15849，0603 封装及模型引用保留 |
| 屏幕控制 | 维持外圈 P6 复位、P7 电源使能；SPI、UART、音频引脚不变 |

模组参考图对 VDDGPIO 建议接 1 µF，另有 VIO 接 4.7 µF 的说明，两者不能混用。本次按参考保留 65 脚去耦，与外部 3V3 分开；没有以“VIO 不悬空”的描述作为 65 脚的直接依据。尚未通过实物确认省去该外部去耦的可行性。

取消按钮后，板上没有物理复位、按下说话或按键打断入口。模组 CEN 有内部上拉，下载复位可用断电重上电完成；CH340K 的 RTS/DTR 没有自动复位连接。对话的启动和打断需由电脑端或后续软件提供，当前没有宣称该软件功能已经实现。

仍为五页原理图，主控页保留原文件名以维持现有引用，图内标题和总览说明已改为主控模组。器件不重新编号，保留删除位号的空号。实体器件由 67 个减为 **62 个**，导出含 4 个虚拟模块共 **66 个器件、294 个引脚、51 个网络**；其中 241 个已连接、53 个未连接。

实际原生网表逐针核对及独立审计通过。ERC 无新增问题；完整五页仍有 B1–B4 四条虚拟模块无封装提示，其他错误、警告为零。已查看修改后的总览和主控页渲染；中文说明保留默认字体、100 mil。C10 使用工程内已验证的 1 µF 器件及相同引脚几何，原理图位号、实例 ID 和位置保留；没有仅修改显示数值而继续绑定 4.7 µF 器件。
