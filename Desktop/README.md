# 桌灵 Windows 上位机

在 Windows 11 安装 uv 后双击 `start.cmd`。也可从仓库根目录运行以下命令。首次运行会按 `uv.lock` 准备 Python 3.12 和依赖。

```powershell
uv run --directory Desktop --locked python app.py
```

程序在系统托盘运行，面板地址为 `http://127.0.0.1:8765`。面板显示 CPU、内存、上下行网速和占用较高的进程。文字可以直接发送。「电脑麦克风」使用 Windows 本机普通话语音识别，语音反馈从当前 Windows 音频输出设备播放。请确认系统已经提供普通话桌面语音识别和语音合成组件。

## 板载麦克风

用 USB-C 数据线连接已烧录[桌灵固件](../Firmware/voice-bringup/README.md)的 BK7258，在 `settings.json` 中填入设备管理器显示的 COM 号。样机默认 COM4。状态面板识别到支持采音的固件后，点击「板载麦克风」，在四秒内说完一条指令。「打断语音」可中止录入或播报。

## 常用指令

| 目的 | 指令示例 |
| --- | --- |
| 查看电脑状态 | 电脑状态、现在内存用了多少、哪个程序占用最高、现在网速多少 |
| 调系统音量 | 音量调到百分之三十 |
| 控制媒体 | 暂停播放、继续播放、下一首、上一首 |
| 启动应用 | 打开 VS Code、打开桌灵项目 |
| 专注计时 | 进入工作模式、结束专注 |

在 `settings.json` 中配置应用绝对路径、命令行参数、语音短语和工作模式。路径支持 Windows 环境变量，参数中的 `{project}` 指向仓库根目录。播放器须提供 Windows 媒体会话。工作模式重复触发沿用现有计时，浏览器在上位机短时离线期间继续倒计时。
